Manage restaurant table bookings, take food orders, and handle payments efficiently with Pinaka POS – a complete Point of Sale system built for WordPress and WooCommerce.

== How Pinaka POS for Restaurants Works ==

Once installed, **Pinaka POS** adds a **Restaurant POS** menu to your WordPress dashboard. From there, restaurant staff can manage tables, reservations, customers, food menus, and orders. The plugin supports dine-in, takeaway, and delivery modes.

Key modules include:
- **Table Booking:** Reserve and manage tables with assigned waitstaff.
- **Order Management:** Take new orders, modify existing ones, and track order status.
- **Menu Management:** Create categories, add dishes, manage availability, and pricing.
- **POS Dashboard:** Real-time sales summary, order flow, and staff performance.
- **Payments:** Accept payments via cash, card, or integrated WooCommerce gateways.
- **Kitchen Display Support:** Seamless coordination between front-of-house and kitchen.

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/pinaka-pos-restaurant` directory, or install the plugin through the WordPress plugins screen directly.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to WordPress Admin Dashboard > Restaurant POS to start using the plugin.
4. Configure your restaurant settings, add menu items, tables, and you're ready to go.
